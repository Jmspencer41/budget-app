# Budget App

An open source, self-hosted budgeting application built from scratch. Supports shared budgets between multiple users, custom categories, and income tracking.

## Status

Early development. Currently building out the core backend API.

## Tech Stack

- **Backend:** Java 21, Spring Boot 3
- **Database:** PostgreSQL
- **Migrations:** Flyway
- **Build tool:** Maven
- **Containerization:** Docker / Docker Compose

## Features (planned)

- User accounts
- Shared budgets between multiple users, with roles (owner/editor/viewer)
- Custom budget categories with recurring limits or savings goals
- Income source tracking, manual or auto-generated recurring entries
- Web app, Android app, and iOS app, all backed by the same API
